# Changelog

## 0.1.0-alpha.1 — 2026-08-22

First public playtest candidate.

### Included

- Complete Tyrian campaign hosted through the original authoritative 35 Hz
  simulation.
- Stereoscopic diorama presentation with scrolling terrain geometry, authored
  height bands, composite enemies, virtual shadows, and stereo-safe level
  effects.
- Left-hand direct steering, conventional thumbstick controls, OpenXR recenter,
  music, sound effects, pause, menus, saves, and lifecycle screens.
- Standalone Meta Quest 2/3/3S/Pro package and Windows x64 PCVR package.
- Legacy-frame fallback for menus, cinematics, and unknown presentation effects.

### Alpha limitations

- Visual and comfort coverage across all levels is still in progress.
- Original menus, cinematics, and story screens remain flat panels.
- Two-player and network play are not part of this playtest.
- PCVR has primarily been tested through Virtual Desktop/VDXR.

See `PLAYTESTING.md` for controls, installation, known limitations, and useful
bug-report details.
